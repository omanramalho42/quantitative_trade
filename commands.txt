⚙️ E no WebStorm

Abra a pasta meu-projeto no WebStorm e configure o interpretador para:

meu-projeto\.venv\Scripts\python.exe

Assim o WebStorm sabe que esse projeto usa o Python da .venv, e não o Python global.

Estrutura que eu recomendo para começar:

meu-projeto/
│
├── .venv/              ← ambiente Python (não vai para o Git)
├── src/                ← código
│   └── main.py
├── tests/              ← testes
├── .gitignore
├── requirements.txt
└── README.md

Se você me disser o que pretende fazer com Python (API, IA, automação, análise de dados, web scraping etc.), eu monto a estrutura inicial já adequada ao projeto.

Simples, mano. Se você estiver com a .venv ativada:

pip install nome-da-lib

Depois atualize o requirements.txt:

pip freeze > requirements.txt
Exemplo

Você já tem:

pandas
numpy

E quer adicionar requests:

pip install requests

Depois:

pip freeze > requirements.txt

Seu requirements.txt será atualizado com as versões instaladas:

numpy==2.5.3
pandas==3.0.6
python-dateutil==2.9.0.post0
requests==2.x.x
...
